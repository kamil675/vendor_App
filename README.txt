PROJECT SETUP

Backend (Laravel)

1. Open terminal in vendor_backend

2. Install dependencies

composer install

3. Create environment

copy .env.example .env

4. Generate key

php artisan key:generate

5. Run migrations

php artisan migrate

6. Start server

php artisan serve

Frontend (React Native)

1. Open terminal in VendorUi

2. Install dependencies

npm install

3. Start Metro

npx react-native start

4. Run Android App

npx react-native run-android
